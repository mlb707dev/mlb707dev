## Featured: ApexPM

A prediction-market trading bot for Kalshi, built inside a governance harness. A strategy layer of two loops drives every trade, every order passes ordered governance gates into a paper, shadow, or locked live book, and everything is journaled, judged, and fed back into the gates.
